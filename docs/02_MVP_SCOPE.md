# 02 — MVP Scope

## MVP içinde olacaklar

### 1. Oyun başlangıcı

- Parti adı
- Parti lideri adı
- Başlangıç bölgesi
- Başlangıç ideoloji etiketi veya parti profili
- Başlangıç bütçesi, enerji ve örgüt kapasitesi

### 2. Ana dashboard

- Hafta bilgisi
- Bütçe
- Enerji
- Gönüllü sayısı
- Ulusal oy oranı tahmini
- Bölgesel destek dağılımı
- Temel metrik kartları
- Kullanılabilir aksiyonlar
- Haftalık olay / haber paneli

### 3. Kaynak sistemi

- Para
- Enerji
- Gönüllü gücü
- İtibar
- Örgüt kapasitesi

### 4. Metrik sistemi

- Medya Gücü
- Kampanya Görünürlüğü
- Genç Seçmen Erişimi
- Yerel Örgütlenme
- Kriz Yönetimi
- Lider Güveni
- Politika Güvenilirliği
- Toplumsal Grup Erişimi
- Finansal Sürdürülebilirlik
- Bölgesel Nüfuz

### 5. Aksiyon sistemi

Aksiyonlar kategorilere ayrılacak:

- Yerel Örgütlenme Araçları
- Toplumsal Grup Araçları
- Medya ve İletişim Araçları
- Finansman Araçları
- Strateji ve Profesyonelleşme Araçları

### 6. Haftalık ilerleme

Oyuncu haftalık aksiyonlarını seçer, sonra “Haftayı Bitir” butonuna basar. Sistem:

- Kaynakları günceller
- Metrikleri günceller
- Kamuoyu desteğini hesaplar
- Rastgele veya koşullu olay üretir
- Yeni haftaya geçer

### 7. Seçim sonucu

52. haftanın sonunda:

- Ulusal oy oranı
- Bölgesel performans
- Güçlü/zayıf alanlar
- Kampanya özeti
- Skor

## MVP dışında bırakılacaklar

- Gerçek Türkiye haritası
- Gerçek parti/aday isimleri
- Multiplayer
- Online hesap sistemi
- Gerçek ödeme sistemi
- Steam entegrasyonu
- Gelişmiş animasyonlar
- Komple backend
- Gerçek haber API entegrasyonu
- Gerçek seçim verisi simülasyonu

## MVP başarı kriteri

MVP başarılı sayılırsa:

- Oyuncu tek oturumda baştan sona kampanya oynayabiliyorsa
- Aksiyonların sonuçları anlaşılırsa
- Her hafta karar alma baskısı oluşuyorsa
- Kaynak kısıtı oyuncuyu düşündürüyorsa
- Aynı aksiyonu tekrar etmek optimal strateji olmuyorsa
